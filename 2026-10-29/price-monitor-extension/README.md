# 皮肤套餐监控（Edge / Chrome 扩展 · 第五人格藏宝阁）

自动刷新藏宝阁页面（首页推荐流 / 搜索结果），扫描每个卖号账号，**当你指定的皮肤出现在这个账号里、且这些皮肤的参考价合计 < 阈值时**，通过**企业微信机器人**推送提醒。

> 关键约定：**皮肤名与参考价由你用 Excel/CSV 提供**（价格来自你的清单，不在页面上取）。页面只负责判断“这个账号拥有哪些皮肤（按名字）”，扩展把清单里命中皮肤的参考价相加，与阈值比较。

## 功能
1. **自动刷新（带随机抖动）**：实际间隔 = 基础间隔 + 0~抖动 秒随机数，避免固定节奏被风控识别。支持整页刷新或仅定时重新扫描。
2. **时段控制**：仅在设定的时段内扫描/刷新；时段外静默空转，不碰服务器。
3. **数据判断**：每个账号卡内提取皮肤名 → 与你的清单匹配 → 累加参考价 → 合计 < 阈值 即命中。
4. **消息提醒**：命中后推送企微（列出命中皮肤与合计参考价 + 账号售价）+ 本地通知；同一账号+同一命中组合只提醒一次（去重）。

## 安装（Edge / Chrome 通用，Manifest V3）
1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 右上角打开「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录 `price-monitor-extension/`。
4. 固定扩展到工具栏，点图标 →「打开配置」。

## 配置项（options 页）
| 配置 | 说明 |
|---|---|
| 启用监控 | 总开关 |
| 监控页面地址 | `*` 通配，如 `https://id5.cbg.163.com/*` |
| 基础刷新间隔(秒) | 抖动前的底，如 60 |
| 随机抖动(秒) | 0~该值随机秒数叠加到基础间隔；0 为固定 |
| 整页刷新 | 关则只重新扫描不重载 |
| 时段控制 | 开启后仅在时段内扫描/刷新 |
| 时段起/止(小时) | 0-23，可跨午夜（如 22→8） |
| 账号卡容器选择器 | 默认 `.product-item.product-item-cards` |
| 皮肤名选择器 | 默认 `.card-item .name-wrap .name` |
| 账号标题选择器 | 去重/展示，默认 `.main-title` |
| 账号售价选择器 | 仅展示，默认 `.row-hd .price` |
| 目标皮肤清单 | 每行 `皮肤名,参考价`；可「导入CSV」读 Excel 导出的 .csv |
| 合计参考价阈值 | 命中皮肤参考价之和 < 该值才提醒 |
| 企微 Webhook | `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx` |

## 风控策略（重点）
- **随机抖动**：`实际间隔 = 基础间隔 + Math.random()*抖动`。例如基础 60s + 抖动 30s → 每次刷新间隔在 60~90s 间随机，无规律。
- **时段控制**：`inWindow()` 判断当前小时是否在 `[起, 止)`（支持跨午夜）。时段外：整页刷新模式**不刷新**、只静默等待；非刷新模式**不扫描**。页面加载初次也只在时段内才扫描。
- **整页刷新去重**：刷新后依靠 `chrome.storage.local.pm_notified` 去重，不会重复打扰。
- 建议基础间隔 ≥ 60s，网易藏宝阁风控严格；若页面要求验证，先手动通过再继续。

## 给你（mr.z）的默认假数据（演示用，正式用请替换）
- 清单：`司药,30` `石榴碟小姐,50` `片刻闲暇,40` `长夜,25` `欧律狄刻,35`
- 阈值：`100`；默认基础 60s + 抖动 30s；时段控制默认关闭。
- 效果示例：某账号同时拥有「司药(30)+长夜(25)」合计 55 < 100 → 命中提醒（前提是页面皮肤名能匹配上）。

## 企业微信机器人 Webhook 获取
企业微信 → 某个群 → 右上角「···」→ 添加群机器人 → 复制 Webhook 地址（含 `key=`）。

## 工作流（等你给 Excel 时）
1. 你把皮肤名+参考价整理成 Excel，导出为 `.csv`（两列：名称,价格）。
2. 扩展配置页点「导入CSV」读入，设好阈值、时段与抖动，保存并应用。
3. 打开藏宝阁对应页面，扩展自动注入；在时段内按随机间隔扫描，命中即推企微。

## 去重逻辑
命中的「账号标题 + 命中皮肤名组合」作为主键存入 `chrome.storage.local.pm_notified`。
刷新后脚本重新读取，已提醒过的不再重复。想重提醒，点「清空已通知记录」。

## 注意事项
- 整页刷新依赖 storage 去重，不会重复打扰。
- `host_permissions` 为 `<all_urls>`，用于匹配任意站点与请求企微接口；仅本地自用。
- 网易藏宝阁风控严格，请勿把刷新间隔设得过短；若页面要求验证，先手动通过再继续。
