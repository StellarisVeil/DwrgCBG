# 皮肤套餐监控（Edge / Chrome 扩展 · 第五人格藏宝阁）

藏宝阁页面监控扩展，两种模式可切换：

- **皮肤套餐模式**：扫描账号卡，当你指定的皮肤出现在这个账号里、且这些皮肤的参考价合计 < 阈值时，推送企微。
- **搜索比价模式**：按你设的关键词周期搜索（价格升序），当某关键词最低价 ≤ 该词目标价时，推送企微。每个关键词可单独写「关键词,目标价」，不写则用全局默认目标价。

> 关键约定：**皮肤名与参考价由你用 Excel/CSV 提供**（价格来自你的清单，不在页面上取）。页面只负责“这个账号拥有哪些皮肤（按名字）”。搜索模式则直接读搜索结果的最低价。

## 功能
1. **自动刷新（带随机抖动）**：实际间隔 = 基础间隔 + 0~抖动 秒随机数，避免固定节奏被风控识别。
2. **时段控制**：仅在设定的时段内扫描/搜索；时段外静默空转，不碰服务器。
3. **数据判断**：
   - 套餐模式：账号卡内提取皮肤名 → 与清单匹配 → 累加参考价 → 合计 < 阈值 即命中。
   - 搜索模式：周期跳转到关键词搜索结果（价格升序）→ 取第一个（最低价）→ ≤ 目标价 即命中。
4. **消息提醒**：命中后推送企微 + 本地通知；通知内附**可点击的商品链接**，点一下直接进商品详情页；同一组合只提醒一次（去重，搜索模式价格创新低会再次提醒）。

## 快速上手（一步一步，给非技术的你）
当前默认就是「搜索比价」模式，且已经帮你预填了 3 个皮肤，你基本零配置就能跑：

1. **装扩展**：打开 `edge://extensions` 或 `chrome://extensions` → 右上角开「开发人员模式」→「加载解压缩的扩展」→ 选本目录 `price-monitor-extension/`。
2. **开配置**：点工具栏里的扩展图标 →「打开配置」。
3. **填 Webhook**（唯一必填）：把企业微信机器人的 Webhook 地址粘到最下方的「企业微信机器人 Webhook 地址」框。没有它无法推消息。
4. **启用**：勾上「启用监控」→ 点「保存并应用」。
5. **开着页面**：在你的 Chrome 里打开藏宝阁任意页面（保持这个标签页在前台）。扩展会自动注入，按随机间隔轮流搜索 3 个皮肤，命中就推企微 + 弹本地通知（带可点链接）。你不用点任何东西。

> 那 3 个皮肤（`于此岸赴宴,300` `蜃景,1000` `赤宴,1200`）已经在配置里了，数字就是各皮肤「最低价目标」——搜索结果最低价 ≤ 该数就提醒。所以第 1~5 步之外你什么都不用动。

### 价格表（Excel/CSV）和扩展是什么关系？
- 我给你的 `skin-monitor-list.xlsx` 只是一个**外面的表格文件**，方便你查看/编辑价格；扩展并不会自动读它。
- 扩展内部自己存了一份同样的数据（就是配置页里的「关键词」框）。所以现在**不需要导入**也能跑。
- 以后你想改清单：直接编辑 Excel →「另存为 CSV（逗号分隔）」→ 在配置页用上方「批量导入清单」选这个 CSV 即可；它会按当前模式填进对应框（搜索模式进「关键词」，套餐模式进「皮肤清单」）。
- 嫌麻烦也可以直接在配置页的框里**手动改文字**（每行 `名称,数值`）。

## 配置项白话说明
- **启用监控**：总开关。不勾就不注入、不扫描。
- **监控页面地址**：扩展往哪些网址注入脚本。默认 `https://id5.cbg.163.com/*` 已覆盖藏宝阁，一般不用改。
- **监控模式**：「搜索比价」= 每个关键词单独搜、看最低价（你当前用的）；「皮肤套餐」= 一个账号里指定皮肤合计价低于阈值才提醒。
- **基础刷新间隔 / 随机抖动**：两次操作之间等的秒数 = 基础间隔 + 0~抖动 的随机数。默认 60 + 30，即 60~90 秒一次，**故意不固定**以免被风控。想更保守就调大。
- **整页刷新**：套餐模式才用（刷新整个页面）；搜索模式始终按关键词跳转，此项无效。
- **时段控制 / 起止**：只在某个时段内干活，时段外只静默等待。默认 9→23 点。比如你只想夜里跑，就设 22→8。
- **商品链接选择器**：命中通知里那个「点此查看」链接从哪取。默认自动取卡片里的第一个链接，一般不用改。
- **搜索关键词**：每行一个 `关键词` 或 `关键词,目标价`。如 `赤宴,1200` 表示搜赤宴、最低价 ≤1200 提醒。当前已预填 3 个。
- **搜索 URL 模板**：搜索用的网址，`{keyword}` 会被替换成关键词。默认已拼好（按价格升序），一般不用改；若你的链接必须带 `refer_sn`，把完整链接粘来、把关键词位置换成 `{keyword}`。
- **最低价目标**：全局默认目标价，仅当某关键词没写 `,目标价` 时兜底。
- **最低价所在元素选择器**：取最低价用哪个页面元素。默认 `.row-hd .price`，一般不用改。
- **企业微信 Webhook**：推消息的地址（必填）。
- **套餐模式专用**（切到套餐才出现）：皮肤清单（每行 `皮肤名,参考价`）、合计阈值、各选择器——用于"一个账号里多个皮肤加起来便宜"的场景。

## 安装（Edge / Chrome 通用，Manifest V3）
1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 右上角打开「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录 `price-monitor-extension/`。
4. 固定扩展到工具栏，点图标 →「打开配置」。

## 搜索比价模式原理
藏宝阁筛选是**服务端 URL 参数驱动**：`/cgi/mweb/pl?keyword=赤宴&order_by=price%20ASC` 即“搜索赤宴并按价格升序”。扩展在标签页内周期性 `location.href = 搜索URL(下一个关键词)`，页面加载后取结果列表第一个卡片的价格（升序→即最低价），与「最低价目标」比较。多个关键词依次轮询，间隔带随机抖动。

## 风控策略（重点）
- **随机抖动**：`实际间隔 = 基础间隔 + Math.random()*抖动`。
- **时段控制**：`inWindow()` 判断当前小时是否在窗口内；时段外不刷新、不搜索、只静默等待。
- **搜索模式低侵扰**：单个标签页轮换跳转，每次只在窗口内、按随机间隔导航一次。
- 建议基础间隔 ≥ 60s；网易藏宝阁风控严格，若页面要求验证先手动通过。

## 去重逻辑
- 套餐：`账号标题 + 命中皮肤名组合` 主键。
- 搜索：`search|关键词|最低价` 主键（价格创新低会再次提醒）。
- 存于 `chrome.storage.local.pm_notified`，刷新/重开仍去重；点「清空已通知记录」可重置。

## 注意事项
- `host_permissions` 为 `<all_urls>`，用于匹配任意站点与请求企微接口；仅本地自用。
- 网易藏宝阁风控严格，请勿把刷新间隔设得过短；若页面要求验证，先手动通过再继续。
- 搜索结果的卡片结构与首页一致（均用 `.product-item` / `.row-hd .price`）的假设已默认；若你实测最低价读不到，把搜索结果页的 HTML 发我，我按实际结构调整选择器。
