# 价格监控提醒（Edge / Chrome 扩展）

自动刷新商品页，当指定字段（默认价格）满足比较条件时，通过**企业微信机器人**推送提醒。
所有关键参数均可配置，**不写死任何平台**。

## 功能
1. **自动刷新**：对监控页面按设定间隔整页刷新（或仅定时重新扫描）。
2. **数据判断**：用 CSS 选择器提取每个商品的目标字段，按「比较符号 + 阈值」判断。
3. **消息提醒**：命中后推送到企业微信机器人，并弹本地通知；同一商品只提醒一次（去重）。

## 安装（Edge / Chrome 通用，Manifest V3）
1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 右上角打开「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录 `price-monitor-extension/`。
4. 固定扩展到工具栏，点图标 →「打开配置」开始设置。

## 配置项（options 页）
| 配置 | 说明 |
|---|---|
| 启用监控 | 总开关 |
| 监控页面地址 | 支持 `*` 通配，如 `https://search.jd.com/Search?keyword=*` |
| 刷新间隔(秒) | 每次刷新的间隔 |
| 整页刷新 | 关则只重新扫描不重载 |
| 商品条目选择器 | 匹配每个商品的 CSS，如 `.gl-item` |
| 价格字段选择器 | 相对商品提取价格文本，如 `.p-price strong` |
| 标题选择器 | 去重主键，可选；留空用条目前 60 字 |
| 比较方式 | `<` `<=` `>` `>=`，默认 `<`（便宜就提醒）|
| 阈值 | 数值 |
| 企微 Webhook | `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx` |

快捷方式：点工具栏图标 →「监控当前页面」，会按当前页域名自动生成地址并刷新启用。

## 企业微信机器人 Webhook 获取
企业微信 → 某个群 → 右上角「···」→ 添加群机器人 → 复制 Webhook 地址（含 `key=`）。

## 示例（以京东搜索页为例，选择器需按实际页面调整）
- 监控页面地址：`https://search.jd.com/Search?keyword=显卡`
- 商品条目选择器：`.gl-item`
- 价格字段选择器：`.p-price strong`
- 标题选择器：`.p-name a`
- 比较方式：`<`
- 阈值：`3000`
- 效果：每 30 秒刷新，凡是价格 `< 3000` 的显卡，首次出现时推送企微 + 本地通知；已提醒过的不会再推。

> 选择器怎么找：在页面上右键商品价签 →「检查」，看它的 class，父级商品的 class 作为「商品条目选择器」，价签的 class 作为「价格字段选择器」。

## 去重逻辑
命中的商品以「标题/条目前 60 字」为主键存入 `chrome.storage.local` 的 `pm_notified`。
刷新后脚本重新读取该记录，已存在的不再提醒。想重新提醒，点配置页「清空已通知记录」。

## 注意事项
- 整页刷新依赖 storage 去重，刷新后不会重复打扰。
- `host_permissions` 为 `<all_urls>`，用于匹配任意站点与请求企微接口；仅本地自用，不涉及上传数据给第三方。
- 若站点强反爬（如淘宝），登录态内通常可绕过，但频繁刷新可能触发验证，请合理设置间隔。
